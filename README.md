# 网页目录

个人网页的入口。首页先选一级目录，再点二级页面进入。

现在有：

- 娱乐 / 冷笑话大全、弱智吧发言、海龟汤大全、我是卧底
- 游戏 / 黑白棋、角度感知、井字棋、跳棋、五子棋、2048、俄罗斯方块、绝对色感、枪战小游戏、开心消消乐、拼豆画板、贪吃蛇、华容道、星跃奇遇、森林冰火人
- 工具 / 计算器、拼豆分析、答案之书、鸡汤之书、金句之书、名人名言之书、手写数字识别

首页可以搜索页面名字。

本地打开 `index.html` 就能用。放到 GitHub Pages 后，地址是仓库页面给出的站点地址。

再加一个网页时：

1. 把页面放进新文件夹，入口写成 `index.html`。
2. 在 `index.html` 的 `CATALOG` 里给对应一级目录加一条，写上标题和链接。
